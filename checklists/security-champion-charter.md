## 3. TIER MODEL

| Tier | Profile | Key Responsibilities |
| :--- | :------ | :-------------------- |
| **Bronze** | Awareness advocate | Promote secure practices, report incidents and weaknesses, review team processes |
| **Silver** | Team practitioner | Review designs, triage findings, deliver team-level training |
| **Gold** | Advanced practitioner | Lead threat modeling, mentor Bronze/Silver, represent team on security forums |
