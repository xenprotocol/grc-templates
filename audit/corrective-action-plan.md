> **Purpose:** Tracks nonconformities from identification to verified
> closure. ISO 27001 Clause 10.1 requires correction (immediate fix)
> AND corrective action (root cause elimination to prevent recurrence).
> A plan without root cause analysis is a band-aid.

> **How to use this template:** one plan per nonconformity. Complete
> the 5-Whys root cause before defining corrective action — the
> correction fixes the symptom, the corrective action fixes the cause.
